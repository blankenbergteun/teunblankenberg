Inloggen

Deze pagina zet je wijzigingen rechtstreeks op GitHub. Daarvoor heb je een sleutel (token) nodig. Die maak je één keer aan:

  1. Open github.com → nieuwe fine-grained token.
  2. Naam: Beheer website. Vervaldatum: bijvoorbeeld 1 jaar.
  3. Repository access: Only select repositories → teunblankenberg.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klik op Generate token en plak de code hieronder.

De token wordt alleen in deze browser bewaard.
